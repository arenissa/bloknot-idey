# Командный блокнот задач

Простой Telegram-бот на Python 3.10+ и aiogram 3. Задачи сохраняются в SQLite и остаются после перезапуска.

## Запуск на Mac

Откройте папку проекта в VS Code и выберите **Терминал → Создать терминал**. Выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и замените `your_bot_token_here` на токен своего бота, полученный у [@BotFather](https://t.me/BotFather) командой `/newbot`. Не публикуйте `.env` и не отправляйте токен в переписку.

```bash
python main.py
```

Откройте своего бота в Telegram и отправьте `/start`. Для остановки нажмите `Ctrl+C`. Для последующих запусков достаточно активировать окружение и выполнить `python main.py`. Нужен доступ к интернету. Одновременно запускайте только один экземпляр с этим токеном.

## Команды

- `/start` — приветствие и подсказки.
- `/add Купить маркеры` — сохранить задачу с автором и датой.
- `/add` без текста — показать пример (затем отправьте полную команду).
- `/list` — все задачи по порядку добавления; длинный список разбивается на сообщения.
- `/list_csv` — файл `tasks.csv`; для пустой базы содержит только заголовки.

В группе можно использовать `/add@имя_бота текст задачи`. CSV отправляется в тот чат, где вызвана команда. Разделитель CSV — точка с запятой; кодировка UTF-8 с BOM для кириллицы. Даты — UTC. Потенциальные формулы в CSV предваряются апострофом для безопасного открытия в таблицах.

**Один экземпляр бота — одна команда и один общий список.** Любой пользователь, имеющий доступ к боту, сможет читать и выгружать все задачи, в том числе добавленные из других чатов. Разграничения доступа и отдельных списков по группам в этом минимальном примере нет.

## Структура

```text
main.py                # Запуск бота и подключение обработчиков
config.py              # Чтение токена и путь к базе
handlers/tasks.py      # Обработка команд
keyboards/commands.py  # Стандартное меню команд Telegram
database/tasks.py     # Создание таблицы, добавление и чтение задач
services/export.py     # Подготовка CSV
services/messages.py   # Разбиение длинного списка
tests/                # Локальные проверки без токена
.env.example           # Образец настроек
requirements.txt       # Зависимости
```

База `data/tasks.sqlite3` создаётся автоматически. Таблица `tasks`: `id`, `text`, `user`, `created_at`. Данные хранятся локально; для резервной копии остановите бота и скопируйте файл базы.

Проверки:

```bash
python -m unittest discover -v
```

Документация: [команды aiogram](https://docs.aiogram.dev/en/latest/dispatcher/filters/command.html), [отправка файлов](https://docs.aiogram.dev/en/latest/api/upload_file.html).
